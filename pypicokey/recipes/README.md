# Recipes do pypicokey

Esta pasta contém "receitas" (guias passo-a-passo) sobre como interagir com os protocolos dos dispositivos PicoKey.

O objetivo é manter a transparência e permitir que qualquer pessoa entenda como os comandos são construídos, sem depender de lógica oculta.

## Conteúdo

- [FIDO2](./fido.md) - Interação via CTAP2
- [OpenPGP](./openpgp.md) - Comandos APDU para Smartcards
- [HSM](./hsm.md) - Gestão de chaves e PKCS#11
