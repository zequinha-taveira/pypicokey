# Recipe: HSM (Hardware Security Module)

Documentação viva de como interagir com o Pico HSM.

## Conceitos
O Pico HSM oferece funcionalidades de armazenamento seguro e operações criptográficas baseadas no padrão SmartCard-HSM.

## Identificação
- ATR contém padrões como `SmartCard-HSM` ou `PicoHSM`.

## Interface
- Utiliza comandos APDU para gestão de chaves.
